# Tinjauan penyusun draf orang tua

Capture dari `parent-practice-check.ps1 -CaptureScreenshots`, PHP 8.1 loopback, 15 Oktober 2026. Akun, paket kapabilitas, entitlement, draf dan soal semuanya sintetis dan dibersihkan seusai pengujian.

- [Daftar dan formulir sesi, ponsel](parent-draft-list-360.png)
- [Editor draf, ponsel](parent-draft-editor-360.png)
- [Editor draf, desktop](parent-draft-editor-1280.png)

Tinjauan manual mencakup informasi fitur belum dapat dikirim, anak tujuan, status draf, label form, susunan dua kolom desktop/satu kolom ponsel, serta daftar berhalaman. Editor ponsel menyediakan tautan langsung ke formulir yang dapat difokuskan agar tidak perlu menggulir melewati sepuluh soal. Teks `<img ...>` merupakan fixture escaping dan tampil sebagai teks, bukan gambar/kode berjalan. Materi berulang sengaja dipakai untuk tes pagination, bukan contoh kursus produksi.

Browser memeriksa daftar, dashboard orang tua, editor, dan baca-saja sesudah pembatalan pada 360/768/1280 px; tidak ditemukan overflow atau kegagalan heuristik label/fokus skip-link. Screenshot ini bukan bukti WCAG penuh, uji keyboard lengkap, pembaca layar, zoom 200%, atau UAT. Pembelian paket dan pengiriman/pengerjaan oleh anak belum tersedia pada fase ini.
